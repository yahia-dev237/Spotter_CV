# Spotter – Flutter app

The Android app of Spotter. See the [main README](../README.md) for the full description.

```bash
flutter pub get
flutter run --release
```

Build an APK for phones:

```bash
flutter build apk --release --split-per-abi
```

The phone file is `build/app/outputs/flutter-apk/app-arm64-v8a-release.apk`.
